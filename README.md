# Albrost Fast Food Website

The website for Albrost Fast Food: the full menu with prices, meals and buckets, photos of the restaurant, opening hours, and both outlets (Fatehgunj and Panigate).

## See the website

Open **https://muzammilkhan2784.github.io/albrost-website/** on any phone or computer. Nothing needs to be installed, and it always shows the latest version.

## Get your own copy (optional)

To have the files on your own computer:

1. Click the green **Code** button at the top of this page.
2. Click **Download ZIP**.
3. Unzip the file and double-click `index.html`.

## Change something

| What you want to change | Where it is |
| --- | --- |
| Menu items, prices, text, phone numbers, opening hours | `index.html` |
| Food photos | `img/cut/` (the `.webp` files) |
| Menu section photos | `img/` (the `.webp` files) |
| Restaurant photos | `img/gallery/` |
| Printed menu (linked from the Full menu section) | `Albrost-Menu.pdf` |

To edit from the GitHub website, open `index.html`, click the pencil icon, make the change and click **Commit changes**. The website updates within a few minutes. You need to be added as a collaborator on this repo first.

## Keeping GitHub up to date

On the main computer, changes made with Claude go to GitHub automatically each time Claude finishes.

If you edit the files on that computer yourself, double-click **`Sync to GitHub.bat`** when you're done.

## Reviews

The Reviews section sends guests to Google to leave a review for either outlet. The site doesn't store reviews itself.

## What's inside

- `index.html`: the whole website
- `img/`: the photos
- `Albrost-Menu.pdf`: the printed menu
- `tools/`: the script behind `Sync to GitHub.bat`. You don't need to open it.
