# Albrost Fast Food Website

The website for Albrost Fast Food, with the full menu, photos, reviews and outlet details.

## See the website

**Open it here: https://muzammilkhan2784.github.io/albrost-website/**

It works on a phone or computer, and nothing needs to be installed.

## Get your own copy

1. Click the green **Code** button at the top of this page.
2. Click **Download ZIP**.
3. Unzip the file and double-click `index.html`.

## Change something

| What you want to change | Where it is |
| --- | --- |
| Menu items, prices, text, phone numbers | `index.html` |
| Food photos | `img/` |
| Restaurant photos | `img/gallery/` |
| Printable menu | `Albrost-Menu.pdf` |

To edit from the GitHub website, open `index.html`, click the pencil icon, make the change and click **Commit changes**. The website updates within a few minutes. You need to be added as a collaborator on this repo first.

## Keeping GitHub up to date

On the main computer, changes made with Claude are sent to GitHub automatically when Claude finishes.

If you edit the files yourself, double-click **`Sync to GitHub.bat`** when you're done.

## What's inside

- `index.html`: the whole website
- `img/`: the photos
- `Albrost-Menu.pdf`: the printable menu
- `tools/`: helper scripts for syncing and running the site
